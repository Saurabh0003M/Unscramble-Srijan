# Unscramble-Srijan (AI LegalTech Platform)

A highly advanced, multi-service LegalTech platform built for the hackathon.

## Architecture

- **`frontend/`**: The modern Case Portal UI.
- **`contract-ai/`**: Deep PDF contract parsing, traffic-light risk badges, and plain-English translation.
- **`caseflow-ai/`**: Intelligent case management, AI model training, and automated caseflow.
- **`scheduler-api/`**: RAG orchestration and automated deadline alerts.

## Quickstart

Just run the unified launcher on Windows:

```cmd
.\run.bat
```

This will automatically create virtual environments, install all dependencies, and launch the microservices.
